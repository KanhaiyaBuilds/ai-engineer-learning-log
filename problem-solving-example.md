Problem-Solving Example

Goal

Learn how to analyze a problem before choosing a solution.

Example: Phone Battery Not Charging

1. Problem

The phone battery stays at 20% while charging.

2. Expected Result

The battery percentage should increase while the phone is charging.

3. Actual Result

After 10 minutes, the battery still shows 20%.

4. Possible Causes

- Charger problem
- Damaged cable
- Power supply issue
- Charging port problem
- Battery or software issue

These are possible causes, not confirmed diagnoses.

5. Test

1. Check whether the charging icon appears.
2. Try a known-working compatible cable.
3. Try a suitable charger and power outlet.
4. Check whether the phone shows any charging warning.

Change one variable at a time so the test results are useful.

6. Solution

Choose a solution only after the tests identify a likely cause.

If the problem continues, seek professional repair rather than guessing.

Engineering Lesson

Do not assume the cause before testing it.

Problem → Expected → Actual → Possible Cause → Test → Solution

Reflection Questions

1. What was the expected result?
2. What actually happened?
3. Which possible cause would you test first, and why?
4. What evidence would confirm that your solution worked?
